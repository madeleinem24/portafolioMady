# Portafolio — Madeleine Morales

Portafolio web de **Madeleine Morales**, diseñadora gráfica. Multimedia, diseño, producción audiovisual y contenido UGC.

## Enlace público

**[https://madeleinem24.github.io/portafolioMady](https://madeleinem24.github.io/portafolioMady)**

## Desarrollo local

```bash
pnpm install
pnpm dev
```

Copiá `.env.example` a `.env.local` y completá las variables necesarias (Cloudinary, EmailJS).

## Deploy

El sitio se publica automáticamente en GitHub Pages al hacer push a `main` (workflow en `.github/workflows/deploy.yml`).
